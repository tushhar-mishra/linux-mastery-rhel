## What it is

**awk** is a small programming language for text that comes in columns. Its name comes from its three authors at Bell Labs (Aho, Weinberger, Kernighan, 1977). On RHEL and most distros, `awk` is **GNU awk** (`gawk`). On Ubuntu, the default may be `mawk`, which is faster but has fewer features. Install `gawk` if a script needs gawk extras.

awk reads input as **records** (normally lines), splits each record into **fields** (columns), and runs your rules in the form:

```
pattern { action }
```
"For every line where *pattern* is true, do *action*."

## Why it exists

Much command output is columns separated by **varying amounts of spaces**: `ps`, `df`, `ls -l`, `ss`, web logs. `cut` can't handle that (topic 018). awk splits on any run of whitespace by default, and it can also filter, do maths, count and format, all in one line. It's the go-to tool for "sum this column", "show filesystems over 80%" or "count requests per IP".

## Analogy

awk is a **spreadsheet with a formula bar, but for the terminal**. Each line is a row and each field is a cell (`$1`, `$2`, …). You write one formula ("if column 5 is above 80, show column 6") and awk applies it to every row.

## How it works inside

1. Before reading anything, awk runs the `BEGIN { … }` block (if there is one).
2. For each line, it splits the line into fields using `FS` (the field separator: by default any run of spaces/tabs, and leading spaces are ignored). It sets `$1`, `$2`, … `$NF` and `NF`, and increases `NR`.
3. It checks each `pattern { action }` rule in order. If the pattern is true (or there's no pattern), it runs the action. A pattern with **no action** means "print the line".
4. After the last line, it runs the `END { … }` block (good for totals).

| Built-in variable | Meaning |
|---|---|
| `$0` | The whole line |
| `$1` … `$NF` | Fields. `$NF` is the last field, `$(NF-1)` the second-to-last |
| `NF` | Number of fields on this line |
| `NR` | Line number counted across all input |
| `FNR` | Line number within the current file |
| `FS` (or `-F`) | Input field separator |
| `OFS` | Output field separator (used between comma-separated `print` items; default space) |
| `RS` / `ORS` | Input / output record separators (default newline) |
| `FILENAME` | The current file name |

**Patterns** you can use: `NR>1`, `$3=="Delhi"`, `/regex/`, `$1 ~ /^web/` (field matches a regex), `$1 !~ /test/` (doesn't match), `a && b`, `a || b`, `BEGIN`, `END`.

**Comma vs no comma:** `print $1, $2` puts `OFS` (a space) between them. `print $1 $2` glues them together.

Always put the awk program in **single quotes**. Otherwise the shell replaces `$1` with its own first argument before awk sees it.

## Commands

Sample `data.txt`:
```
Name Age City
Tarun 24 Jaipur
Ravi 30 Delhi
Priya 27 Mumbai
Neha 25 Pune
```

```bash
awk '{print $1, $3}' data.txt
```
```
Name City
Tarun Jaipur
Ravi Delhi
Priya Mumbai
Neha Pune
```

```bash
awk 'NR>1 && $2 > 25' data.txt
```
```
Ravi 30 Delhi
Priya 27 Mumbai
```
- `NR>1` skips the header. No action means "print the line". Without `NR>1`, the header would also match: comparing the text `"Age"` with `25` is done as a **string** comparison, and it comes out true.

```bash
awk 'NR>1 {sum+=$2; n++} END {if (n) print "Average age:", sum/n}' data.txt
```
```
Average age: 26.5
```
- Variables start at 0. `END` runs after the last line. `if (n)` avoids dividing by zero on empty input.

```bash
awk 'NR>1 {printf "%-8s %3d  %s\n", $1, $2, $3}' data.txt
```
```
Tarun     24  Jaipur
Ravi      30  Delhi
Priya     27  Mumbai
Neha      25  Pune
```
- `printf` formats: `%-8s` = text left-aligned in 8 characters, `%3d` = number in 3 characters.

```bash
awk -v min=26 'NR>1 && $2 >= min {print $1}' data.txt
```
```
Ravi
Priya
```
- `-v name=value` safely passes a shell value into awk: `awk -v min="$LIMIT" …`.

```bash
awk 'NR>1 {count[$3]++} END {for (c in count) print c, count[c]}' data.txt
```
```
Jaipur 1
Delhi 1
Mumbai 1
Pune 1
```
- **Arrays** with text keys (associative arrays): `count[$3]++` counts per city. The order of `for (c in count)` isn't guaranteed; pipe to `sort` if order matters.

### Admin one-liners

```bash
awk -F: '$3>=1000 && $3<65534 {print $1}' /etc/passwd
```
```
alice
bob
```
- Regular (human) users. `-F:` makes `:` the separator. UID 65534 is `nobody`.

```bash
df -hP | awk 'NR>1 && $5+0 > 80 {print $6, $5}'
```
```
/var 87%
```
- Filesystems more than 80% full. `$5` is like `87%`. `$5+0` forces it to a number (awk reads the leading digits). `-P` keeps each filesystem on one line.

```bash
ps -eo pid,%mem,comm --sort=-%mem | awk 'NR<=6'
```
```
    PID %MEM COMMAND
   1234 12.4 java
    987  3.1 mysqld
...
```
- The header plus the top 5 memory users.

```bash
sudo awk '/Failed password/ {print $(NF-3)}' /var/log/secure | sort | uniq -c | sort -rn | head -3
```
```
    212 203.0.113.50
     87 198.51.100.7
      3 192.168.56.1
```
- The IP is 4th from the end of each "Failed password … from IP port N ssh2" line.

```bash
awk '{print $1}' /var/log/httpd/access_log | sort | uniq -c | sort -rn | head
awk '$9 ~ /^5/ {print $7}' /var/log/httpd/access_log | sort | uniq -c | sort -rn | head
```
- Top client IPs; top URLs that returned 5xx errors. In the common web log format, field 9 is the status code and field 7 is the path.

```bash
ip -4 -o addr show scope global | awk '{print $2, $4}'
```
```
enp0s3 10.0.2.15/24
enp0s8 192.168.56.10/24
```
- Interface and address (topic 060).

```bash
awk -F, 'BEGIN{OFS="\t"} {print $1, $3}' users.csv
```
- CSV in, tab-separated out. (For CSV with quoted commas inside fields, use a real CSV tool.)

```bash
awk 'length($0) > 120' app.log | wc -l     # lines longer than 120 characters
awk '!seen[$0]++' file                      # remove duplicate lines WITHOUT sorting (keeps first-seen order)
awk 'NR%2==0' file                          # every second line
```
- `!seen[$0]++` is a famous idiom: print a line only the first time it's seen.

### Which tool when?

| Need | Best tool |
|---|---|
| Keep lines that match a pattern | `grep` |
| Columns with a single-character delimiter | `cut` |
| Columns with varying whitespace, conditions, sums, reports | `awk` |
| Find-and-replace, in-place edits | `sed` |

## Where you'll use it

- **Monitoring checks in scripts:** "alert if any filesystem > 90%" in one line.
- **Log reports:** requests per IP, 5xx per endpoint, average response time.
- **Reshaping command output** for other tools: `kubectl get pods --no-headers | awk '$3!="Running" {print $1}'` lists pods that aren't running.
- **Interviews:** "print the second column of lines containing error" → `awk '/error/ {print $2}' file`.

## When it breaks

| Symptom | Cause | Fix |
|---|---|---|
| The header line shows up in numeric filters | Text vs number comparison is true | Add `NR>1` |
| `$1` is empty or wrong | Double quotes let the shell replace `$1` | Single-quote the program |
| Wrong columns on CSV | The default separator is whitespace | `-F,` |
| `$5 > 80` misbehaves on `85%` | `85%` is text | `$5+0 > 80` |
| `division by zero` in `END` | No lines matched | Guard with `if (n)` |
| A gawk feature fails on Ubuntu | Default awk is `mawk` | `sudo apt install gawk` |

## Quick recap

- `awk 'pattern { action }'`. Fields are `$1…$NF`, the whole line is `$0`. `NR` = line number, `NF` = field count.
- `-F` sets the separator; `-v` passes shell values; `BEGIN`/`END` run before/after the input.
- Arrays (`c[$1]++`) for counting; `printf` for neat output; `$x+0` to force a number.
- Use awk when columns are space-aligned or you need logic; grep/cut/sed for simpler jobs.

**Interview questions**

1. *What are `NF` and `$NF`?* `NF` is the number of fields on the current line; `$NF` is the last field.
2. *How do you pass a shell variable into awk?* `awk -v name="$var" '{ … name … }'`.
3. *Print the second column of lines containing "error".* `awk '/error/ {print $2}' file`.

**Scenario question** (answer out loud first, then compare)

> *"Show me how you'd find which users are using the most memory on a box right now, with one command line."*

**Model answer:**
1. `ps -eo user,rss --no-headers` gives each process's owner and resident memory in KiB.
2. awk sums per user with an array: `awk '{m[$1]+=$2} END {for (u in m) printf "%-12s %8.1f MB\n", u, m[u]/1024}'`.
3. Pipe into `sort -k2 -rn | head` for the top users.
4. Mention the caveat: RSS counts shared pages (libraries, shared memory) in **every** process, so totals overstate real use. PSS (`smem`, `/proc/PID/smaps_rollup`) is fairer (topic 093).

**Likely follow-ups:**
- *Why `$NF` rather than `$7`?* `$NF` is always the last field, even when the number of columns varies.
- *How do you use a shell variable in awk?* `awk -v limit="$LIMIT" '$2 > limit'`.
